## Overview

This is a subtractive polyphonic synthesizer plugin/application I implemented using the JUCE framework. The list of features and UI layout is heavily inspired by PIGMENTS. 



![alt text](../thesynthesizer/cover.png)



# Features

- 2 sound engines 
- Envelope and LFO modulation of parameters
- An FX rack 
- Frequency Modulation
- polyphony, monophony, legato, protamento, etc.
- preset saving/loading
